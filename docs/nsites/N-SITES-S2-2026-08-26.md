# Council of AI — MCP install

Independent AI governance **measurement** over MCP. We measure, sign and preserve the
evidence; regulators and accredited bodies decide. **Not a certification body, not a notified
body.**

## Install (npx)
npx -y @csoai/mcp-core
## Configure (Claude Code / Cursor / any MCP client)
{"mcpServers": {"council-of-ai": {"command": "npx", "args": ["-y", "@csoai/mcp-core"]}}}
## Tools
- gspc.board — the signed measurement board (14 measured of 14 quotable; 22-axis registry)
- gspc.verify — stranger-verify a signed card offline
- gspc.crosswalk — jurisdiction provision map (EU / US-IL / CN)
- connections.search — is this contact already in our outreach ledger? (never duplicate)
## Honesty
Measurement, never certification. UNMEASURED is a first-class answer. Cards carry a
measurement-not-approval disclaimer. We never claim accreditation before granted.
## Sources
councilof.ai · github.com/CSOAI-ORG/councilof-ai
